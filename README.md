# Quiz Game

## Overview of the Project

Quiz Game is a simple Python-based console application that asks the user five questions and checks their answers. The program keeps track of the user's score and displays the final score after all questions have been attempted.

The project is designed as a beginner-friendly Python program to demonstrate basic programming concepts such as lists, loops, user input, conditional statements, and variables.

## Features

- Displays a quiz game title.
- Contains 5 different questions.
- Takes answers from the user.
- Checks each answer automatically.
- Displays "Correct!" for a correct answer.
- Displays "Wrong!" for an incorrect answer.
- Maintains the user's score.
- Displays the final score at the end of the quiz.
