# Project Statement

## Problem Statement

The aim of this project is to develop a simple quiz game using Python. The program asks the user five predefined questions, accepts their answers, checks whether the answers are correct, and calculates the final score.

This project helps demonstrate the use of basic Python programming concepts in a simple and interactive way.

## Scope of the Project

The project is a basic console-based quiz application developed using Python.

The current scope includes:

- Displaying five quiz questions.
- Taking answers from the user.
- Comparing the user's answers with the correct answers.
- Displaying whether the answer is correct or wrong.
- Maintaining the user's score.
- Displaying the final score after all questions are completed.

The project can be expanded in the future by adding more questions, multiple-choice options, different categories, and difficulty levels.

## Target Users

The target users of this project are:

- Students learning Python.
- Beginners practicing basic programming concepts.
- Users who want to play a simple quiz game.
- Students who want to practice general knowledge questions.

## High-Level Features

- Simple console-based interface.
- Five predefined questions.
- User input for each question.
- Automatic answer verification.
- Correct and wrong answer feedback.
- Score calculation.
- Final score display.
- Beginner-friendly Python implementation.
